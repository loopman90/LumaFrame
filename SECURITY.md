# Security And Privacy

LumaFrame is designed as a local-first media plugin.

## Privacy

LumaFrame does not upload:

- photos
- videos
- filenames
- folder names
- metadata
- usage data

LumaFrame does not include:

- analytics
- telemetry
- cloud processing
- accounts
- external APIs
- AI image analysis
- remote databases

## Source Scanning

LumaFrame only scans folders explicitly added as Sources by the user.

The community build scans vault folders through the Obsidian API. It does not scan external desktop folders with direct filesystem access.

## Reporting Security Issues

Please do not open a public issue for a sensitive security report.

Contact the maintainer through GitHub first and share only the minimum information needed to describe the issue.
