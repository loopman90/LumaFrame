LumaFrame

Turn photos, GIFs and videos from your Obsidian vault into a calm gallery, fullscreen photo frame and ambient media player.

Built for local media

LumaFrame creates a LumaFrame Media folder in your vault, lets you drop media into the empty player and scans only vault folders you add as Sources.

Quick UI

Switch playback modes, adjust transition timing, favorite media and jump to the gallery without opening settings.

Gallery View

Browse media, start playback from a selected item, create notes, hide files from LumaFrame and manage playlists.

Privacy First

No telemetry, accounts, AI processing, cloud sync, analytics or remote database. Media stays local.

Manual Install

  1. Download main.js, manifest.json and styles.css from the latest release.
  2. Place them in YourVault/.obsidian/plugins/lumaframe/.
  3. Restart Obsidian and enable LumaFrame from Community plugins.
  4. Add photos or videos to LumaFrame Media, or drop media onto the empty LumaFrame player.
